```
프로세스:
1. 5분 경과 후 스케줄러가 PENDING 주문 감지
2. 주문 상태를 CANCELLED로 변경
3. Kafka 이벤트 발행 (order.cancelled)
4. 재고 복구 (Reserved → Available)

```
